# T3 Code

- `roster`: `orchestrator_capabilities`
- **Writers:** `t3_thread_launch({message, workspaceStrategy:"worktree", baseRef})`, then `t3_thread_wait` / `t3_thread_read`, and `t3_thread_interrupt` to cancel. `delegate_task` has no workspace parameter, so never use it for writers.
  - Pass the provider and model if the live schema accepts them.
  - If it doesn't, the thread uses its default model. Record that model as the cook, and pick the taster's family relative to it.
- **Tasters, scouts and designers:** `delegate_task({task, target:{providerInstanceId, model}, role:"review"|"research"|"design", mode:"async", clientRequestId})`
  - Use a new `clientRequestId` for each new attempt.
  - Reuse the same one only to replay an attempt whose acknowledgment was lost.
- `status`: `task_status`. `cancel`: `task_cancel`, which also cancels the child's own children.
- `schedule`: `schedule_task`.
- **Reconciling a launch with no acknowledgment:** list the live threads and tasks with whatever `t3_thread_*` or `task_status` tools the schema offers, and check the branch for pushes. If neither proves the attempt ended, it stays `uncertain`.
- `notify`: end your turn.
- Messaging a task restarts it, so a fix round is a new task.
